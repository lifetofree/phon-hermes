# Superclick — verified research (2026-09-03)

Product: **Superclick** (superclick.app) — macOS all-in-one media converter by KAKU INC. (1151 N. 12th St, San Mateo CA). Disambiguation: NOT superclick.co (a different product); this is the media-converter app, confirmed by user context "convert media type".

Status: **public beta (free)** → $19.99 one-time lifetime license at GA. Mac App Store distribution. Universal binary (Apple Silicon + Intel).

## Features (official site)
- 4 media types: image (PNG/JPG/WEBP/HEIC/GIF), video (MP4/MOV/AVI/MKV/WebM/M4V), audio (MP3/WAV/M4A/AAC), PDF
- Batch conversion, right-click Finder integration, menu bar quick actions
- Built-in editing: crop, resize, rotate, compress
- Video downloader from 1,000+ websites (per FAQ)

## Pricing (official /pricing)
- Beta: free, no license key required, no ads (dev confirmed in Reddit launch thread r/macapps/1i7klqu)
- GA: $19.99 one-time (some regional stores show $29.99), free updates
- No trial, no refunds (official FAQ)

## Cons / risk angles (verified from primary sources)
- EULA: requires **Full Disk Access** to work outside sandbox; broad clause — app "may access, collect, use, and disclose any information and data" for "business purposes" → privacy trade-off worth a section
- Closed-source (vs ffmpeg/HandBrake open-source)
- macOS only, no Windows/Linux
- Beta: dev says "not perfect yet"; advanced codec control (bitrate/2-pass/hardware accel toggle) absent
- Video downloader = gray area re: site ToS (same as yt-dlp)

## Dev signals (Reddit launch thread 1i7klqu)
- Beta ~3 months with small community; daily bug fixes; Telegram support group; free during beta

## Competitor frame used in draft
ffmpeg (control, free, high learning curve) / HandBrake (GUI video, free) / Clop (~$5, HEIC) / online converters (ads, size limits, server upload). Superclick = convenience/one-app layer, not a codec-control tool.
