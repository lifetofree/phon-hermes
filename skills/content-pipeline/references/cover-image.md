# Cover Image Workflow — Title บน/ล่าง + เน้นคำ + ภาพประกอบ (Benz DNA)

> ที่มา: บทเรียนจาก Benz DNA ตัวจริง (ซีรีส์ Composio 28 พ.ย. 2026) + cover spec ของบ้าน (content-system.md 2.1)
> ขอบเขต: **แนะนำข้อความ (title บน/ล่าง + คำเน้น) และ concept ภาพ** — การจัดวางบนภาพเป็นหน้าที่ของพรเสมอ (ห้ามวาง text ลงภาพเอง)

## 0. กฎเหล็ก (อ่านก่อนทุกครั้ง)

1. **ภาพปกห้ามมี Text/Logo/Headline ในภาพ** — title บน/ล่างที่เราแนะนำ = ข้อความสำหรับพรวางทับเองภายหลัง
2. **มาสคอตบังคับในทุกภาพ content** — "a white duck mascot with a mischievous face, wearing a red backwards cap and black glasses" (อ่าน /mnt/hermes-agent/rakazo/kit/adduck-SOUL.md ก่อนงานแรก)
3. **การจัดวาง/ตัดต่อ title ลงภาพ = พรทำเอง** — เราส่งแค่: ภาพ + title บน + title ล่าง + คำเน้น + alt text
4. dispatch งาน gen = ผ่าน routine one-shot ให้ Image Gen (ห้าม gen เอง)

## 1. Title บน (headline หลัก) — เกณฑ์ Benz DNA

- **เจาะจง ไม่กว้าง**: ชื่อระบบ/ผลิตภัณฑ์จริง + คำสัญญารูปธรรม (บทเรียน 548: "Vivo X500: แบตใหญ่ ตัวเล็ก กล้องเป็นระบบ" — ห้าม "3 จุดเปลี่ยนของระบบฮาร์ดแวร์")
- **สัญญาตัวเลขต้องมีเลขจริงในเนื้อ** (บทเรียน 528): title พูด "500+ บริการ" ได้เฉพาะเมื่อเนื้อมีลิงก์เอกสารรองรับ + วันที่ตรวจ
- **ห้ามคำเกินจริงบนปก**: มหาศาล / ตัดขาด / สิ้นเชิง / ปฏิวัติโลก = ตัดทิ้ง (Benz ตัดทุกครั้ง)
- **สั้น 1 บรรทัด**: อ่านจบใน 2-3 วินาที, ไม่เกิน ~8 คำไทย
- **เสียงคน ไม่ใช่ AI**: ไม่มีสัญลักษณ์ (—), ไม่มีวงเล็บแทรก, ไม่ใช้สูตร "3 สิ่งที่...ที่ต้องรู้"

ตัวอย่างถูก (จาก Composio): "Rakazo × Composio แยกสมองออกจากมือเท้า" / "ต่อ AI Agent ให้ 500+ บริการ โดยไม่ถือคีย์เอง"

## 2. Title ล่าง (sub-headline) — เกณฑ์

- **เสริม ไม่ซ้ำบน**: ขยายคำสัญญา / บอกเงื่อนไข / เกณฑ์มอง ไม่ใช่ทวน title บนอีกครั้ง
- ยาวกว่าบนได้ (~1 ประโยค) แต่ยัง 1 บรรทัด
- ดีที่สุด = ประโยคที่ Benz เคยยกว่า "คมและจำง่าย" จากบท (เช่น "ทุกอย่างนี้เป็นของมนุษย์ ไม่ใช่ของโมเดล")

## 3. การเน้นคำ (emphasis)

- **≤ 2 คำต่อ title บน / ≤ 1 คำต่อ title ล่าง** — เน้นเยอะ = ไม่มีอะไรโดด
- เน้นเฉพาะ: คำสัญญารูปธรรม / ตัวเลขที่ตรวจได้ / คำตรงข้าม (สมอง vs มือเท้า)
- **ห้ามเน้น** คำเกินจริง, คำอารมณ์, คำที่เนื้อไม่ส่งมอบ
- ส่งรูปแบบเป็นข้อความ: `title: ... [เน้น: คำX, คำY]` — ไม่ตกแต่งเอง

## 4. Concept ภาพประกอบที่เข้ากัน

**สไตล์ล็อก (พรยืนยัน 28 พ.ย.): 3D render เป็ดชิบิ + ฉากเต็ม (มี background เสมอ ห้ามพื้นเปล่า)** — ห้ามสีน้ำ ห้าม flat vector
- ภาพมาตรฐาน 4 ใบอยู่ใน container Image Gen: `/home/rakazo/shared/cover-image/refs/std-1..4-*.jpg` (อ่านด้วย vision ก่อน gen ทุกงาน แล้วคัดลอก: ผนัง teal, พื้นไม้เข้ม, ชั้นวาง gadget ยุคเก่า/แก้ว/ต้นไม้/ลูกบิด Rubik, ไฟสายป้ายสีทอง, กรอบศิลปะนามธรรม, โน้ตก๊กสี, แสง cinematic อุ่น)
- เป็ดขนฟูนุ่มชิบิหัวโต หมวกแดงกลับหลัง แว่นดำ (ใส่ hoodie สีเทาได้) จะงอยส้ม
- **prop ประจำบทเล่าเรื่อง**: 1-2 ชิ้นที่ตรงใจความ (ไฟกระดาษ+บัวรดน้ำ = แก้ incident / ตู้ร้อน 50° = server ร้อน / โต๊ะ 3 ตัวไฟเรืองแสง = งานขนาน / หุ่นยนต์พิมพ์งาน+ตรายาง = บอททำ คนอนุมัติ)
- เป็ด 1 ตัวเป็นพระเอก หรือ 2 ตัวเล่าคู่ (คู่เหมือน/เทียบสองมุม) ได้
- อ่านบทจบก่อน → เลือกอุปมาจริงของบท ห้าม concept ที่ต้องอธิบายยาว

## 4.5 แต่งโจทย์เองจากบทความ (autoclaw mode — ไม่ต้องรอพรสั่งว่าจะ gen แบบไหน)

พรใช้จริง: ยัดบทความให้ → ตัวแต่งโจทย์อ่านเอง → gen เลย สูตร:
1. **อ่านบทจบ** → ตอบ 2 คำถาม: "ใจความของบทคืออะไร" + "ผู้อ่านควรรู้สึกอะไร 1 วินาที"
2. **เลือกอุปมา 1 อัน** จากบท (ภาษาที่บทใช้เอง เช่น "แยกสมองออกจากมือเท้า", "ตู้ร้อน 50°")
3. **เลือก prop 1-2 ชิ้น** ที่เล่าอุปมานั้น (ห้าม prop ที่ต้องอธิบาย)
4. **ประกอบฉากมาตรฐานบ้าน** (§4: ห้อง teal kit) + มาสคอตชิบิ + prop
5. **เขียน positive** ตามลำดับ: สไตล์ → ตัวละคร (identity 3 ชิ้น + ท่า) → ที่อยู่/ฉาก → props → แสง → องค์ประกอบบนล่างว่าง → "no text" / **negative** มาตรฐาน + สิ่งที่ต้องแบนเป็นกรณี
6. ห้ามเติมสิ่งที่ผู้ใช้/บทไม่ได้พูดถึง (แบรนด์อื่น ตัวละครใหม่ สโลแกน)
7. แก้ภาพซ้ำ: ประกาศทุกครั้งว่า "อะไรที่ห้ามเปลี่ยน" กันตัวละคร/องค์ประกอบหลุดยุค

## 5. Gen spec (คงเดิม — ไม่เปลี่ยน)

- ปก: **606×370 แนวนอน** (gen 608×376 แล้ว resize) — template `z-image-template-cover-server.json`
- โมเดล: Z-Image Turbo หลัก / SDXL สำรองเทียบ (GPU1, ComfyUI :8190)
- แก้ node "3" = prompt (อังกฤษ), node "6" = width/height, seed สุ่มใหม่ทุกครั้ง
- prompt lessons: identity ต้น positive / ห้าม "NO x" ใน positive (x ไป negative) / ยิง 2-3 seed เลือกใบดี
- ชื่อไฟล์: `{YYYYMMDD-CNT-SLUG}-cover-606x370.jpeg` → ~/ComfyUI-Shared/output/imagegen/

## 5.5 Alt Text — บังคับคิดพร้อมภาพทุกใบ (ไม่ต้องรอใครขอ)

ทุกภาพที่ gen = ต้องส่ง alt text ภาษาอังกฤษกลับมาด้วยเสมอ (ปก/ภาพประกอบ/มาสคอต ทุกชนิด) — เป็นส่วนของงาน ไม่ใช่ metadata เสริม

- **เขียนเป็นประโยคบรรยายภาพ** ไม่ใช่คำสำคัญ: ใคร/ทำอะไร/ที่ไหน/อารมณ์ภาพ
- กล่าวถึงมาสคอต identity สั้น ๆ ("a white duck mascot in a red backwards cap and black glasses…") และเชื่อมกับใจความบทความ
- 8–20 คำ (ปก) / 10–30 คำ (ภาพประกอบ) — ห้ามยาวเป็นย่อหน้า
- ห้ามขึ้นด้วย "image of / picture of" (screen reader บอกอยู่แล้ว)
- ห้ามใส่ตัวอักษรที่แสดงบนภาพ (ภาพเราไม่มี text อยู่แล้ว) และห้ามใส่ hashtag
- ตรวจง่าย ๆ: ปิดตาอ่าน alt text แล้วต้องเห็นภาพในหัวได้ใกล้เคียงของจริง

ตัวอย่าง (ปก Composio): "A white duck mascot wearing a red backwards cap and black glasses splits into a thinking half and a mechanical hands-and-feet half, clean cartoon style on a soft blue background."

## 6. FLOW (อัตโนมัติ — IG autopilot ตั้งแต่ 28 พ.ย.)

**ระบบรันเองทุก 30 นาที (routine "IG cover autopilot") — ไม่ต้องรอ Hermes สั่ง:**
1. IG อ่าน Content Drafts DB → หาบท Status draft/rewritten ที่ยังไม่มีปก (เทียบ cover-index.json ของตัวเอง)
2. IG แต่งโจทย์เองตาม §4.5 → gen 3 seed → QC ตาม §4 checklist → resize → QA record + index อัปเดต
3. รายงาน Working Out Loud ในแชท: ไฟล์ + title set + alt text
4. พร/Hermes เห็นรายงานแล้วดูได้ทุกเมื่อ — งานไหนไม่ชอบสั่งทบทวนได้ตรง ๆ
- งานเร่งเฉพาะกิจ (Hermes/พรสั่งตรง) = ตัดคิว autopilot มาก่อนเสมอ
- Design Keeper = auditor ตามงาน (ไม่ต้องคอยสั่งรายบท)
