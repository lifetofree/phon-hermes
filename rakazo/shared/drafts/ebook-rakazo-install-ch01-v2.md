## 01 — Chapter One — รู้จัก Rakazo — และ 3 เส้นทางเริ่มต้น

### ส่วนเล่า — เสียงพร (phvoice)

เล่มนี้เริ่มที่เครื่องของเราเอง บอทรันใน Docker บนเครื่องเรา ไม่ต้องจ่ายผ่านเว็บ เส้นทางบนคลาวด์ยังอยู่ในเล่มนี้ แต่เป็นทางเลือก ไม่ใช่ขั้นแรกที่ทุกคนต้องผ่าน

[เคสจริงรอพรเติม — ห้ามแต่ง]

### หัวใจ — Rakazo คืออะไร

Rakazo คือระบบบอทที่สั่งงานด้วยการแชท บอทแต่ละตัวมีบทสนทนา ความจำ routine และคอมพิวเตอร์ของตัวเอง งานที่มอบไว้ยังทำต่อได้ทั้งบนเว็บ เดสก์ท็อป และมือถือ

บอทเชื่อมกับแอปที่เราใช้อยู่แล้ว ทั้ง Gmail Slack Notion GitHub รวมกันหนึ่งพันสี่ร้อยกว่าแอป ให้จัด routine ทำงานซ้ำทุกวันแล้วรายงานกลับแชทเดิม และก่อนทำงานที่อ่อนไหว ระบบ Approvals ถามเราก่อนทุกครั้ง
### คำสั่ง (cmd) — กล่องใช้ คุณ ตามสเปกเล่ม

1. เส้นทางแนะนำ — Docker ในเครื่อง: ติดตั้ง desktop app จาก rakazo.com (Mac Windows Linux ระบบเดียวกับบนเว็บ Linux AppImage ต้องมี FUSE 2) เปิดครั้งแรกเลือก This computer ถ้าเครื่องยังไม่มี Docker แอปหา Docker Desktop ให้ติดตั้งต่อเอง (Linux ใช้ Docker Engine) เมื่อแอปถามตำแหน่งที่บอทจะรัน ให้เลือก Docker เพื่อให้บอทอยู่ในเครื่องแยกของตัวเอง ทุกอย่างรวมคอมพิวเตอร์ของบอทรันบนเครื่องคุณ ปิดแอปแล้ว routine ยังรันต่อ ถ้าจะหยุดทั้งหมดให้เลือก Quit and Stop Bots ในเมนู
2. ทางเลือก — Cloud บนเว็บ ถ้าไม่อยากลง Docker: เปิด app.rakazo.com แล้วล็อกอินด้วยบัญชี rakazo.com ใช้ได้ทันทีในเบราว์เซอร์ [รอพรเติม: ราคา/เงื่อนไข cloud]
3. กรณีทีม — Existing instance: ถ้าทีมรันเซิร์ฟเวอร์ไว้แล้ว เลือก Existing instance กรอก Server address แล้วกด Check connection

### ตารางเทียบ — เส้นทางต่างกันตรงไหน

| เส้นทาง | ระบบรันที่ไหน | เหมาะกับ |
|---|---|---|
| เครื่องเรา — This computer | Docker บนเครื่องผู้อ่าน รับบัญชีเดียว | ใช้ประจำ ไม่ต้องจ่ายผ่านเว็บ |
| Cloud บนเว็บ | เซิร์ฟเวอร์ของ Rakazo ล็อกอินผ่านเบราว์เซอร์ | เริ่มเบา ไม่อยากติดตั้ง |
| self-host — Existing instance | เซิร์ฟเวอร์ที่ทีมตั้งและคุมเอง | ใช้ร่วมกันทั้งทีม |
