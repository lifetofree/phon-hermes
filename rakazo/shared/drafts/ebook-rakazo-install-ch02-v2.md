## 02 — Chapter Two — ทางเลือก: ใช้ Cloud บนเว็บ ถ้าไม่อยากลง Docker — สมัคร สร้างบอทแรก พื้นฐานการแชท

### ส่วนเล่า — เสียงพร (phvoice)

เล่มนี้วาง Docker ในเครื่องไว้เป็นเส้นทางหลัก บทที่แล้วเรียงสามเส้นทางให้แล้ว บทนี้เป็นทางเลือกสำหรับคนที่ยังไม่อยากติดตั้งอะไรลงเครื่อง การเริ่มบนเว็บไม่มีขั้นติดตั้งให้หลุดกลางทาง เปิดเบราว์เซอร์ สมัครบัญชี แล้วเห็นระบบทำงานจริงต่อหน้า ถ้าตัดสินใจแล้วว่าจะลง Docker ในเครื่อง ข้ามบทนี้ได้เลย ไม่มีอะไรในเล่มผูกให้ต้องเริ่มที่เว็บก่อน

docs เขียนไว้ว่าบอทแต่ละตัวทำงานต่อได้ทั้งบนเว็บ เดสก์ท็อป และแอปมือถือ งานที่เริ่มบนเว็บจึงไม่ได้ถูกตรึงอยู่ในเบราว์เซอร์ ย้ายผิวการใช้งานภายหลังได้ โดยประวัติและความจำยังอยู่กับบอทตัวเดิม การตัดสินใจที่หนักกว่า เช่น จะรัน instance ของตัวเองหรือไม่ เกิดหลังจากเห็นของจริงแล้ว ไม่ใช่ก่อน

หน้าเริ่มต้นของ docs ชี้สองทางไว้ตรง ๆ ลงชื่อเข้าใช้ที่ app.rakazo.com หรือรัน instance ของตัวเองตาม self-hosting guide ส่วนราคาและเงื่อนไขฝั่งเว็บ docs สองหน้าที่อ้างในบทนี้ยังไม่มี จึงเว้นไว้ให้พรเติมเอง

### คำสั่ง (cmd) — กล่องใช้ "คุณ" ตามสเปกเล่ม

1. เปิด app.rakazo.com แล้วสมัครบัญชีหรือลงชื่อเข้าใช้ — ไม่ต้องติดตั้งอะไรลงเครื่อง
2. สร้างบอทแรก — บอทตัวแรกถูกสร้างให้เองเมื่อสมัคร จะเพิ่มบอทถัดไป กดปุ่ม Create ด้านบนของ sidebar แล้วเลือก New bot และตั้งชื่อ จากนั้นบอกงานเป็นคำพูดธรรมดา สิ่งที่ยังขาด เช่น แอปที่ต้องเชื่อมหรือ sign-in บอทเป็นฝ่ายถามเอง
3. ทดลองแชท — พิมพ์งานง่าย ๆ ในช่องพิมพ์แล้วกด Enter คุณพิมพ์ต่อระหว่างที่บอทกำลังทำงานได้ และกด Stop เพื่อหยุดรอบทำงานปัจจุบัน เมื่อบอทต้องการอะไรจากคุณ มันโพสต์ card ไว้ในแชท ค่อยกดตอบภายหลังได้
