Before You Start
ก่อนเริ่มอ่าน
เสียงพร — ตัวอย่างโครง (รอ copy จริง)

เล่มนี้ไม่ได้สัญญาว่าจะเปลี่ยนชีวิตใคร — มันคือคู่มือติดตั้งระบบชิ้นหนึ่ง ติดตั้งเสร็จ มีบอทที่ทำงานได้จริง แค่นั้น

พรเขียนจากขั้นที่ลงมือทำเองทั้งหมด ทุกคำสั่งในเล่มอ้างเอกสารทางการของ Rakazo เท่านั้น — ถ้าอะไรยังไม่ยืนยัน เล่มจะเขียนว่ายังไม่ยืนยัน ไม่เดาแทน

ในเล่มนี้ "ส่วนเล่า" กับ "ส่วนคำสั่ง" แยกกันชัดเจน — ส่วนเล่าคือที่มาและเหตุผล ส่วนคำสั่งอ่านแล้วลงมือทำตามได้ทันที แบบฝึกและ Field Sheet ท้ายเล่มใช้กระดาษเล่มนี้กรอกได้เลย

Chapter One
รู้จัก Rakazo — และ 3 เส้นทางเริ่มต้น
เปิดบทด้วยเรื่องจริงของพร

[เคสจริงรอพรเติม — ห้ามแต่ง]

[ย่อหัวใจ: Rakazo คืออะไร — บอทผ่านแชท + เครื่องมือที่เชื่อมได้ + คอมพิวเตอร์ที่บอทใช้งานได้]

เลือกเส้นทาง — ตัวอย่างโครง
  1. เริ่มเบาสุด: ใช้บนเว็บ — ไม่ต้องติดตั้งอะไร
  2. ใช้ประจำ: ติดตั้ง desktop app แล้วเลือก server ที่ใช่
  3. ใช้ร่วมทีม: ต่อ Existing Instance ที่ทีมตั้งไว้

Cloud / เครื่องเรา / self-host ต่างกันตรงไหน — ตารางเทียบสั้น 3 แถว [รอ copy จริง]

แหล่งอ้างอิงบทนี้: rakazo.com/docs.md (ดึง 17 พ.ย. 2026)

Chapter Two
เริ่มบนเว็บ — สมัคร สร้างบอทแรก พื้นฐานการแชท
ส่วนเล่า — ตัวอย่างโครง

[ทำไมเส้นทางเว็บเหมาะเป็นจุดเริ่ม — ไม่ต้องติดตั้ง เห็นระบบทำงานก่อนตัดสินใจลงเครื่อง — รอ copy จริง]

คำสั่ง — ตัวอย่างโครง
  1. เปิด app.rakazo.com แล้วสมัครบัญชี [ขั้นแท้จาก docs — รอ copy จริง]
  2. สร้างบอทแรก [ตั้งชื่อ / เลือกโมเดล — รอ copy จริง]
  3. ทดลองแชท: สั่งงานง่าย ๆ 1–2 คำสั่ง [รอ copy จริง]
แหล่งอ้างอิงบทนี้: rakazo.com/docs.md + docs/bots-and-chats.md (ดึง 17 พ.ย. 2026)

Chapter Three
ติดตั้ง Desktop App — Mac / Windows / Linux
ส่วนเล่า — ตัวอย่างโครง

[จุดที่คนติดตั้งสะดุดบ่อย = หน้าเลือก server ครั้งแรก — บทนี้วางแผนให้ตัดสินใจก่อนถึงหน้านั้น — รอ copy จริง]

คำสั่ง — ตัวอย่างโครง
  1. ดาวน์โหลดแอปตามระบบ [ลิงก์/ชื่อไฟล์ — รอ copy จริง]
  2. Linux: ไฟล์ AppImage ต้องมี FUSE 2 [รอ copy จริง]
  3. เปิดครั้งแรก เจอหน้าเลือก server 3 ทาง: Rakazo Cloud / This computer / Existing instance — เทียบสั้น 3 ทาง [รอ copy จริง]
  4. เปลี่ยน server ทีหลังได้ + อัปเดตเป็นอัตโนมัติ [รอ copy จริง]
แหล่งอ้างอิงบทนี้: rakazo.com/docs/desktop-app.md (ดึง 17 พ.ย. 2026)

05
Chapter Five
Existing Instance — ต่อ server ทีม + ให้บอทใช้เครื่องเรา
ส่วนเล่า — ตัวอย่างโครง

[สองทิศทางในบทเดียว: เราต่อไปที่ server ทีม / เครื่องเรากลายเป็นคอมพิวเตอร์ที่บอททีมมาใช้ — รอ copy จริง]

คำสั่ง — ตัวอย่างโครง
  1. เลือก Existing instance → กรอก Server address → Check connection [รอ copy จริง]
  2. ให้บอทใช้เครื่องเรา: เลือก Docker หรือ Use this computer — ต่างกันตรงไหน [รอ copy จริง]
  3. จัดการเครื่องที่อนุญาต: Settings → General → Computers [รอ copy จริง]
  4. ข้อควรระวังด้านความปลอดภัย [รอ copy จริง]
แหล่งอ้างอิงบทนี้: rakazo.com/docs/desktop-app.md (ดึง 17 พ.ย. 2026)

Using the Field Sheet
วิธีใช้แบบฝึก

คุณไม่ต้องทำครบทุกเส้นทาง — เลือกเส้นทางเดียวที่ตรงกับการใช้งาน แล้วติ๊ก checklist ของเส้นทางนั้นจนครบ ก่อนไปต่อ ถ้าติดตรงไหน กลับไปที่บทของเส้นทางนั้น แล้วไล่คำสั่งใหม่ทีละข้อ

ช่องเขียนว่างใช้จดค่าที่ตั้งไว้ เช่น ทาง server ที่เลือก หรือ address ของ instance ทีม — เผื่อครั้งหน้าต้องตั้งใหม่แล้วจำไม่ได้
