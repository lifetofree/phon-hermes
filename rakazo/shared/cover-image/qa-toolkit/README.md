เครื่องมือวัดคุณภาพไฟล์ปก/ภาพประกอบ 1:1 ตาม **character sheet v1.2** (มาสคอตแอดดัก)
ใช้วัดจากพิกเซล ไม่ตีความภาพ — รันได้บนเครื่อง DK โดยไม่ต้องใช้ GPU / ไม่ต้องยิง ComfyUI

## ติดตั้ง/รัน (ทุกสคริปต์ใช้ `uv run` → ไม่ต้อง pip install เอง)

```bash
uv run --quiet --with pillow --with numpy --with scipy python3 qa_summary.py <file.png> [...]
```

## สคริปต์

| ไฟล์ | ทำอะไร |
|---|---|
| `qa_summary.py` | รายงานหลัก 4 ข้อใน 1 บรรทัด: md5, ขนาด, top20 edge/spread, bot30 edge/spread, แถบเนื้อหา, จุดที่มีสีแรง |
| `qa_cover.py` | รายงานละเอียดเป็นสาย: edge ต่อแถว, row-detrended residual (กัน gradient หลอกว่าเป็นวัตถุ), profile ทุก 32 แถว |
| `cap_metric.py` | **v2**: วัดเรขาคณิตหมวก/ปาก/แว่น + EXACT facts (red_left_of_beak / red_over_beak_rows / red_over_glasses / red_right_of_beak ด้วยแดงเข้ม r−g>140 ที่ไม่จับปากส้ม) + แยกช่องขาวหน้าหมวกว่าเป็นสเปกคูลาร์หรือช่องเปิด (วัด red-cover รอบ 4 ด้าน + width-by-row) |
| `cap_check3.py` | **v2**: ช่องขาวหน้าผากระหว่างหมวกกับแว่น — แก้การหาแว่นเป็น union ของ dark components ทุกก้อนในบริเวณหน้า (เดิมใช้ก้อนเดียว ≥300px ทำให้ master 70095fbc ที่แว่นเป็น 2 เลนส์รายงาน "glasses not found") |
| `cube_count.py` | นับ component สีเขียว (กล่อง) และหาห่วงเหลือง (วงที่มีรูข้างใน) พร้อม bbox |
| `text_check.py` | ค้นหา component เล็กสีเข้มที่มี edge สูง = ตัวอักษร/โลโก้ที่อาจหลุด |
| `compose2.py` | canvas surgery: ฟาดสีสะท้อนให้จาง + สร้างพื้น glossy ใหม่ใต้แนว 70% (ไม่กิน GPU) |
| `fit_band.py` | ย่อภาพทั้งใบให้เนื้อหาพอดีในแถบ 20–70% + เติมบนเทา/ล่างพื้น (ไม่กิน GPU) |
| `check_black_cols.py` | **v3 (22 พ.ย. 2026)**: ตรวจ **แนวตั้ง** — คอลัมน์ที่พิกเซลดำ (max≤8) ≥50% ของแถบเนื้อหา rows 21–67% + ความสว่างขอบซ้าย/ขวา 40 px (เทียบกลางภาพ) → จับแถบดำขอบซ้าย–ขวาที่ `qa_summary.py` ตรวจไม่ได้ |

## เกณฑ์ผ่าน (character sheet v1.2)

- **บน 20%** = เทาอ่อนว่าง · `top20 max_edge` ≲ 3 · ไม่มีวัตถุ ไม่มีเงา ไม่มีตัวอักษร
- **ล่าง 30%** = พื้น glossy ว่างจริง · `bot30 max_edge` ≲ 2 · ไม่มีวัตถุ/เงา/สะท้อน
- **แถบกลาง 20–70%** = ตัวละคร + วัตถุทั้งหมด
- **หมวกแก๊ปสีแดงสวมกลับหลัง** + เห็นสายปรับหัวเข็มที่หน้าผาก
- **ห้ามมีตัวอักษร/ตัวเลข/โลโก้** ในภาพ

## ข้อจำกัดที่ต้องรู้ (สำคัญ — เกิดจากการวัดจริง 21 พ.ย. 2026)

1. **proxy ทิศหมวกให้ค่าเดียวกันเกือบทุกเฟรม** → proxy บอก "หมวกอยู่ขวาของปาก" ได้ แต่แยก
   "กลับหลัง" ออกจาก "หันหน้า" ไม่ได้ (ผลจาก 17 เฟรม: `d_cx` +39…+78 px, ปากอยู่ซ้ายของหมวกทุกเฟรม)
   → **ต้องตัดสินทิศหมวกด้วยตา** (ช่องเปิดหน้าหมวก + สายปรับหัวเข็มที่หน้าผาก + บิลชี้ไปข้างหลัง)
2. **รอยสะท้อนทำให้ edge สูงในล่าง 30%** → ต้องวัด "row-detrended residual" ไม่ใช่ edge ดิบ
   (gradient พื้นเรียบมี edge ต่ำ แต่ gradient ของพื้น glossy มี edge สูงเล็กน้อย)
3. **diffusion นับจำนวนไม่แม่น** — "8 กล่อง" ออกมา 6 ลูกแทบทุก seed · ต้องยอมรับหรือรีเซนเดอร์หลาย seed
   และเขียนคำสั่งเชิงพื้นที่แทนการนับ
4. **ชื่อไฟล์ชนกันระหว่างบอท** — shared/ ของแต่ละบอทเป็นคนละ mount → ตั้งชื่อไฟล์ให้มี prefix
   ของตัวเองเสมอ (เช่น `-dk-`) และรายงาน md5 + path + มิติ + เวลา + แนบไฟล์จริงทุกครั้ง

5. **`qa_summary.py` ตรวจแค่แนวนอน (top20/bot30) → แถบดำขอบซ้าย–ขวาผ่าน QA ได้**
   (เกิดจริง 22 พ.ย. 2026: ไฟล์ LDE build v2 ทั้ง 5 seed มีแถบดำขอบ 76–406 คอลัมน์ แต่ QA รายงานผ่าน)
   → **ต้องรัน `check_black_cols.py` เพิ่มทุกครั้ง** วัดในแถบเนื้อหา (rows 21–67%) ไม่ใช่ทั้งความสูงภาพ
   (แถบบน/ล่างไม่ใช่สีดำ → วัดทั้งภาพได้ 0 ทั้งที่มีแถบดำจริง)
