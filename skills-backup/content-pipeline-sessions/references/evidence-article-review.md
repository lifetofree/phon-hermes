# Evidence-article review: foreign-model drafts, owner real cases, sim-vs-real classes

## A. Reviewing a draft FILED BY ANOTHER MODEL ("ตรวจ")

"ตรวจ" on a foreign-model draft (page already in Content Drafts, often paired with a research/KB node) is a READ-ONLY loop — report verdict + from→to fixes, rewrite only on an explicit owner order:

1. Dump the Notion page: properties FIRST (the Source prop carries the citation list to verify against), then all blocks as text. Extract the body to scratch, run the battery, and run the sibling scan over posts/ + web-archive/ + vault/artifacts/ exactly as for own drafts. Note the battery's pronoun counter is approximate: eye-audit every พร/เรา hit with context (lookalike families like แพร่หลาย, compounds like เรากำลัง) and log counter-vs-eye both.
2. Verify every load-bearing claim against PRIMARY sources — never the draft's citations-of-citations. Raw-fetch recipe that works here: `journals.plos.org/article?id=<doi>` for full text, `pmc.ncbi.nlm.nih.gov/articles/<pmcid>` for open reviews, PubMed eutils (`esearch` → `efetch`) for abstracts behind paywalls, `api.crossref.org/works/<doi>` for author lists, venue, page numbers. Check quoted strings VERBATIM inside the fetched text before grading a quote HIT. Cross-check every number the draft hangs its spine on (sample sizes, pooled-study counts, protocol ranges, ages).
3. Report: fact-check results, from→to fixes ranked by weight, battery/sibling numbers — then stop. Apply only on "ปรับเลย"-class go.

Two attribution traps this class keeps producing — check both before declaring a draft clean:
- An AUTHOR SURNAMED like a famous institution reads as the institution: pull the Crossref author list before letting a surname carry organizational weight — "รีวิวของ Cochrane" names a person surnamed Cochrane, not the Cochrane Collaboration, and in an evidence-ceiling post that misread inflates authority exactly where the post argues caution. When both a same-surname author and the institution exist, attribute the claim to the specific team; the surname-author stays in the Source prop only.
- A RANGE OF MEANS is not a participant range: "mean ages ranged 14–36 years" describes each study's average, not the people — a draft writing "อายุระหว่าง 14–36 ปี" overstates precision and hands the critic a free catch. Whenever a source reports a range OF means/medians, the draft must say "ค่าเฉลี่ยของแต่ละงานอยู่ระหว่าง…".

On an explicit rewrite order: archive the incoming version verbatim FIRST (header "reconstructed from Notion blocks" when no paste file exists), build the posts/ file with a full guard header declaring the case class (FP lookalikes, sibling-guard axes, battery targets), then rebuild the SAME Notion page in place (delete-all + typed-block append, quote and closer bold, read-back line-by-line) — never create a sibling page.

## B. Owner real case inside an evidence article

When the owner supplies a personal trial (temperatures, durations, rounds, felt result) for a research-grounded post, the case class flips to grade 1 — พร narrates the scene, the analysis stays class-level reported-speech — and the case is written under the same evidence discipline as the citations:

- Third-party-reported numbers stay reported speech: "ตามตัวเลขที่สถานที่แจ้งไว้" for venue-supplied temperatures — never assert them as self-measured.
- Never invent context the owner did not state: no purpose (no "หลังซ้อม") if they didn't say why; never intensify their reported feeling ("ตัวเบา สบายตัว" stays bare).
- The case's protocol differing from the studied protocol is an ASSET, not a defect: write it as a live example of "ยังไม่มีสูตรมาตรฐาน" from the reviews — the mismatch IS the ceiling made concrete. Real-critic confirmation exists: this move was praised and flagged for MORE emphasis.
- The felt result maps to the subjective measure the research actually used (soreness ratings) — one summary line classifying it ("ความรู้สึก ไม่ใช่ตัวเลขการฟื้นตัว") is KEEP-grade; a critic quotes such a line back as the post's heart.
- n=1 never confirms: the case illustrates the boundary; the closer carries the purchase-feeling-vs-purchase-recovery tension the case set up.
- A movement order that survived a real round: personal scene → proposed mechanism (hedged from the first sentence) → measured results → limitations → comparison → scope/safety.
- Safety framing is heavier for trial-narrating posts: state the article is not a protocol recommendation, and specific numbers (e.g. a very cold bath) must not read as try-at-home recipes.

## C. Sim-vs-real diff — round-5 catch classes (feed into every pre-send checklist)

- **Sim defense = critic target:** where a pre-send review DEFENDED a title's claim as "ข้อสรุปของ paper เอง", the real critic's heaviest catch was that title. A source's own conclusion licenses the BODY's claim, never the HEADLINE's strength — headline-strength ≤ source-conclusion; treat any sim DEFENSE as a critic-target flag.
- **Population fusion via time-bridge:** two studies from different populations/questions (healthy post-exercise vs clinical pain patients) chained by "หนึ่งทศวรรษถัดมา" read as one evidence line — bridge different-context research with "อีกบริบทหนึ่งของการใช้ X", never with elapsed time, and state the later work is not a follow-up of the first.
- **Outcome-verb ambiguity:** expand every comparative verb into what was actually measured — "เสียกำลังน้อยกว่า" = less loss versus the passive group, not faster full recovery.
- **Recipe/safety framing:** see B above — the critic asks for the not-a-recommendation line on trial-narrating posts.
- **Pooled-subset honesty:** wherever a total is named ("18 งาน"), state the pooled subset carrying each outcome ("ผลรวมอาการเมื่อยมาจาก 13 งาน") — a total without its subset reads as measured-everywhere.

Tally note: sim pre-cleans attribution/word-level completely (real critic raised zero register issues once those landed pre-r1); the real critic's unique catches are all claim-precision — that layer stays sim-blind.

## D. Critic-picked gate riding in the paste

A real critique may end with a gate AND the critic's own selection plus reasons. The owner forwarding the paste untouched = adoption: the critic's pick IS the gate answer, un-chosen options keep the roles he assigns them (opener / limitation layer — never competing theses), and a "ไม่ได้ขาดข้อมูล — จัดลำดับ + คมประโยคเท่านั้น" directive becomes a publish KEY of its own: no new facts, no new sources, reorder per the critic's beat map, sharpen sentences only. Added information grades as a violation, not as richness.
