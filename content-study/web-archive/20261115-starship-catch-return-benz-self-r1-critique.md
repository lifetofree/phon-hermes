# รอบวิจารณ์ r1 — starship-catch-return (news-event single)

**ก่อนตัด ขอชมตรงที่ควรชมก่อน:** ตัวเลขยืนยันเป๊ะและมีต้นทางครบ (สิบสี่รอบ / ยี่สิบสองชั่วโมงครึ่ง / สามเที่ยวบินทดสอบ — ตรงกับแหล่งทั้งสาม), ไม่เอ่ยแบรนด์จริงใน body ตามกติกาสายข่าว, และเลนส์ที่เลือก ("มือรับถูกสร้างไว้ก่อนปล่อย") เป็นเลนส์เดียวจริง ไม่กระจาย — โครงข่ายของโพสต์เดินถูกทาง ปัญหาทั้งหมดที่เหลืออยู่ที่ชั้นตีความ

**1. ชื่อเรื่องอ้างกฎของ "งาน" ทั้งโลก โดยมีหลักฐานแค่ทีมเดียวหนึ่งครั้ง**
"งานไม่ได้จบตอนปล่อย มันจบตอนถูกรับกลับ" — ประโยคนี้เป็นกฎสากล แต่กรอบหลักฐานของโพสต์คือ ทีมหนึ่ง ยานหนึ่ง เที่ยวบินเดียว จับได้เป็นครั้งแรกเมื่อวานนี้ อีเวนต์ยืนยันว่า "ทำแบบนี้ได้จริง" ไม่ได้ยืนยันว่า "งานทุกงานจบที่ตรงนั้น" — ชื่อเรื่องวิ่งเร็วกว่าหลักฐานที่โพสต์พามา

**2. ตัวอย่างย้อนแย้งอยู่ในงานเดียวกับที่โพสต์หยิบมา — แล้วโพสต์ไม่เห็นมัน**
เที่ยวบินเดียวกันนี้ มีส่วนล่างที่ถูกวางให้รับเหมือนกัน แต่รับไม่ได้ จบลงอีกแบบหนึ่ง โพสต์เลือกเห็นครึ่งที่แขนปิดรับได้ แล้วเขียน "งานจบตรงที่มันกลับมาถึงแขนที่รออยู่" เป็นประโยคปิด ทั้งที่ตัวอีเวนต์เดียวกันแสดงขอบเขตของประโยคนั้นชัด ๆ: มีแขนรออยู่ = เงื่อนไขจำเป็น ไม่ใช่เงื่อนไขเพียงพอ โพสต์ที่ขาย "การออกแบบวงรับ" แต่ไม่พูดถึงรอบที่วงรับทำงานไม่สำเร็จ คือโพสต์ที่เลือกหลักฐาน

**3. "งานปล่อยกับงานรับถูกออกแบบเป็นโครงเดียวกันตั้งแต่ต้น" — ใครพูดประโยคนี้**
แหล่งที่ยืนยันได้: หอตัวเดียวกันปล่อยและรับ / รับส่วนล่างมาแล้วสามเที่ยว / ยานชิ้นบนเที่ยวนี้ครั้งแรก ไม่มีแหล่งไหนพูดคำว่า "ออกแบบเป็นโครงเดียวกันตั้งแต่ต้น" — นั่นคือชั้นตีความเรื่อง design-intent วางเรียบเป็นข้อเท็จจริง โพสต์เอวิเดนซ์ชั้นเอกสาร ทุกการอ้างเรื่องเจตนาของทีมต้องมีแหล่ง หรือลงมาเป็นชั้นตีความที่ hedge ตัวเองชัด

**4. "มันยืนอยู่ตรงนั้นตั้งแต่ก่อนยานจะขึ้นไป" — ก่อนยานอะไร ขึ้นไปเมื่อไร**
ประโยคนี้กำกวมสองชั้น: ก่อนเที่ยวบินนี้ (จริง — หอมีอยู่แล้ว) หรือก่อนยานเคยขึ้นครั้งแรกเลย (ไม่มีแหล่งยืนยัน) — และจุดที่โพสต์ต้องการจริงมีแค่ชั้นแรก ซึ่งพูดให้เป๊ะลงได้โดยไม่เสียแรงเลย

**5. "ปล่อยงานออกไป ปล่อยข้อความออกไป ปล่อยระบบขึ้นไปใช้จริง" — สามคลาสที่กลับมาไม่เหมือนกัน วางเรียงเป็นอันเดียว**
งานที่ส่งต่อให้คนอื่นทำ ไม่ได้กลับมาถึงมือเรา ข้อความที่ปล่อยออกไป มือรับอยู่ที่ผู้รับ ไม่ใช่ฝั่งเรา มีแค่ระบบที่วนกลับมา (feedback, บั๊ก, การใช้จริง) ที่มีจุดรับจริง สามอันนี้ไม่ใช่ตัวอย่างของเรื่องเดียวกัน — มันคือหนึ่งตัวอย่างที่ยืนได้ กับสองตัวอย่างที่แทบไม่มี "กลับมา" ให้รับซะด้วยซ้ำ ยกมาเรียงเดียวกันแล้วโครงของ quote ที่ตามมาจะพังตอนผู้อ่านเทียบกับชีวิตจริง

**6. "เราออกแบบการปล่อยออกไปได้ดีมาก" — ใครคือ "เรา" และดีอะไรให้เป๊ะ**
ประโยคประสบการณ์จัดวางบนโพสต์ที่หลักฐานทั้งหมดเป็นเอกสารข่าว ไม่มี case ของ "เรา" แม้แต่ชิ้นเดียวในนี้ และ "ดีมาก" เป็นคำชมลอย ไม่มีอะไรในโพสต์แสดงว่าเราปล่อยแล้วไม่มีมือรับ — ถ้าจะใช้ เปลี่ยนเป็นคำถามของคนอ่าน ("เคยไหม ปล่อยอะไรออกไปแล้วนับว่าจบ") แล้วให้คนอ่านตอบเอง อย่าตอบแทนคนอ่าน

**7. "งานจบ" พูดซ้ำสามจุด — ชื่อเรื่อง / quote / ย่อหน้าปิด**
คำว่า จบ โผล่ห้าจุดใน body เดียว (57 คำ) — insight เดียวควรเต็มที่ตำแหน่งเดียว ตำแหน่งอื่นต้องทำงานต่างหน้าที่ ไม่ใช่พูดซ้ำให้หนา ตอนนี้ทั้งสามจุดเป็นประโยคเดียวกันสลับถ้อยคำ ความหนาไม่ได้ช่วย มันบัง

**8. โครงนี้ใกล้ตระกูลของสองโพสต์ก่อนหน้าเกินไป แล้วยังไม่ตัดตัวเองออก**
"งานจบที่..." อยู่ตระกูลเดียวกับ publish ชิ้นสำคัญสองชิ้นก่อนหน้า (ชิ้นที่จบได้จริงแล้วสมองถึงเชื่อว่าไปข้างหน้า / การนับความก้าวหน้าของสมอง) — ตระกูลนั้นพูดความรู้สึกภายใน โพสต์นี้พูดโครงสร้างภายนอก (วงรับที่ออกแบบไว้) แต่ draft ไม่เคยแยกตัวเองออกจากตระกูลนั้นเลย เอาประโยค quote ไปแปะโพสต์เก่าก็ยังอ่านลื่น ซึ่งแปลว่ามันยังไม่มีตัวตนของตัวเอง — ต้องมีบรรทัดที่ตัดชัดว่า "จบ" ที่นี่ไม่ใช่ความรู้สึกว่าได้ไปข้างหน้า แต่เป็นโครงรับของงานที่วางไว้ก่อนปล่อย

**9. ตัวเลขสองตัวเป็นของประดับ**
สิบสี่รอบ ยี่สิบสองชั่วโมงครึ่ง — สวย แต่ไม่ทำงานให้เลนส์เลย ตัดออกแล้ว thesis ไม่พัง ตัวเลขเดียวที่ทำงานจริงคือ "สามเที่ยวบินทดสอบ" (บันไดที่พิสูจน์ว่าแขนรับไม่ใช่ของใหม่วันนี้) — ถ้าจะเก็บสองตัวที่เหลือ ต้องให้มันทำงาน (ยิ่งไปไกลแค่ไหน จุดรับก็ยังอยู่ตรงเดิม) ไม่งั้นตัด

**10. จุดที่ต้องยกให้: กติกาสายข่าวถูกรักษาครบ**
ไม่เอ่ยแบรนด์ ไม่เอ่ยประเทศ เลขเป็นคำไทย ไม่มี '?' ทุก fact มี "ตามรายงานข่าว" นำ — วินัยชั้นรายงานของ draft นี้เต็มเปอร์เซ็นต์ ปัญหาทั้งหมดที่วิจารณ์มาอยู่ชั้นตีความล้วน ๆ

**ถ้าตัดจนเหลือกระดูก:**
- ยานวนโคจรสิบสี่รอบ กลับมาโหนข้างหอ แขนกลปิดรับทั้งชิ้น — ครั้งแรกของยานชิ้นบน (รับส่วนล่างมาแล้วสามเที่ยวบิน)
- บรรทัดขอบเขต: เที่ยวบินเดียวกันมีชิ้นที่รับไม่ได้ — มีแขนรอ ไม่ได้แปลว่ารับได้ทุกชิ้น

- คำถามปิด: สิ่งที่เราปล่อยออกไป มือรับของมันอยู่ตรงไหน
