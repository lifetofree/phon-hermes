# Immersive Adduckivity — immersive.adduckivity.com

เว็บแอป interactive ของ Duck OS (Next.js, v1.0.4-STABLE) — เครื่องมือที่หล่อโปรโตคอลจากบทความให้เป็นระบบที่ "รันได้จริง" ภาษาอังกฤษ กลุ่มเป้าหมาย Neurodivergent Creators (ADHD/MDD)

Tagline หลัก: "Stop Fighting Your Brain. Build systems that work with it."
หลักการบนหน้าแรก: Systems over willpower. Assets over effort. Momentum over motivation.

## เครื่องมือ 4 ตัว (แต่ละตัวมีหน้า /guide อธิบาย + ตัวแอป)

| เครื่องมือ | บทบาท | สิ่งที่แก้ | เทียบโปรโตคอลบทความ |
|---|---|---|---|
| The Atomizer (/atomizer) | Executive Tool | Task avoidance / executive function block / overwhelm — ย่อยงานเป็นท่าทางทางกายภาพ 2 นาที AI-powered, ใช้หลัง Emergency Recovery เพื่อกลับเข้างาน | ACT-05 Atomizer Protocol |
| Emergency Recovery (/momentum) | Fail-Safe | Spiral/overwhelm — 5 steps ~40 นาที หลัก "สำหรับ signal ไม่ใช่ crash — รันตอนรู้สึกว่ากำลังจะดิ่ง อย่ารอจนพัง" | Recovery Protocol V1 / Circuit Breaker |
| Protocol Builder (/protocol-builder) | System Architect | แผนพังเพราะต้องตัดสินใจสด — map momentum เป็น 3D constellation (node 4 ชนิด: action/timer/tool/ignition), โหมด Build+Flow, เชื่อม Ignition+Atomizer+Recovery เป็น arc เดียว, save ในเครื่อง | LOGS/ACT ทั้งระบบ |
| Ignition (/ignition) | Quick Launch | อาการ frozen — 600 วินาที 3 เฟส (Spark 120s ขยับกาย → Target เขียน 1 เป้า → Launch จัดสภาพแวดล้อม) "no willpower, system does the work" | Momentum Protocol / morning-kickstart 600s |

หน้าอื่น: /start (daily system), /blog (คัดจาก wp.adduckivity.com)

## จุดที่ bots ควรรู้

- นี่คือ "ชั้นผลิตภัณฑ์" ของ Duck OS: บทความ (wp) = Knowledge, immersive = Tools ที่ขาย/ให้ใช้
- ตัวเลขจริงจากแอป: 2 นาที/อะตอม, 600 วินาที Ignition, 5 steps ~40 นาที Recovery, ~15 นาที session แรกของ Atomizer
- Emergency Reset 2 นาที อยู่บนหน้าแรกเสมอ (⚠️ Emergency Reset — 2 min)
- ภาษาอังกฤษทั้งเว็บ — ต่างจาก wp ที่ไทย: ถ้า ADDUCK ทำคอนเทนต์โปรโมว์ immersive ต้องสลับภาษา
- โครงหน้าแรกแก้ปัญหา 3 อาการตรงๆ: "Can't make yourself start" → Atomizer, "Spiral when overwhelmed" → Recovery, "Plans collapse without structure" → Protocol Builder
