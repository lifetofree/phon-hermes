# D-with-primary gate — owner ตอบ "D ทั้งหมด แต่แกนหลักคือ X"

เมื่อ critique ปิดด้วยเมนู A/B/C/D owner จะตอบ "D โดยมี X เป็นแกนหลัก" เสมอ — ตอนนี้ถือเป็นรูป gate มาตรฐาน

## เคสที่เกิด
- [[pair-078]] — "D โดยมี C เป็นกลไกหลัก" (ตกผลึก/สนุก)
- [[pair-079]] — "D แต่แกนหลักคือ A" (ข้อจำกัดของการล็อก)
- [[pair-080]] — "D โดยใช้แกนเป็นข้อ A" + double gate (เกณฑ์ผูกงานปัจจุบัน)
