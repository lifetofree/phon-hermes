# ถ้า AI เป็นคน โมเดลคือสมอง แล้ว harness คือทุกส่วนที่เหลือ

**Excerpt:** ถ้า AI เป็นคน โมเดลคือสมอง แล้ว Harness คือทุกส่วนที่เหลือ Agent ไม่ได้เกิดจากสมองที่เก่งอย่างเดียว แต่เกิดจากระบบรอบตัวที่พาความคิดไปทำงานร่วมกับเครื่องมือและโลกภายนอกได้อย่างเสถียร

### Agent ไม่ได้มีแค่สมองที่คิด แต่ต้องมีส่วนที่พาความคิดไปทำงานด้วย
.
เวลาเริ่มทำงานกับ AI Agent มักมีคำถามหนึ่งตามมาเสมอ
AI Harness คืออะไร แล้วต่างจาก Model อย่างไร?
ลองนึกภาพว่า AI เป็นคนคนหนึ่ง
Model คือสมอง ส่วนที่รับข้อมูล ประมวลผล และสร้างคำตอบ
ส่วน Harness คือร่างกายและระบบที่ทำให้สมองนั้นทำงานกับโลกภายนอกได้
มันเป็นส่วนที่จัดเตรียมข้อมูลและบริบทส่งให้สมอง รับผลลัพธ์กลับมา จัดการขั้นตอนถัดไป และเชื่อมต่อกับเครื่องมือที่จำเป็นต่อการทำงาน
.
ถ้ามีแค่สมอง เราอาจคิดและตอบคำถามได้
แต่การทำงานให้สำเร็จยังต้องมีส่วนอื่นเข้ามาช่วย
ต้องมีวิธีรับข้อมูล ต้องมีลำดับว่าจะทำอะไรก่อนหลัง ต้องมีช่องทางใช้เครื่องมือ และต้องมีวิธีนำผลลัพธ์ที่ได้ไปทำงานต่อ
สิ่งเหล่านี้ไม่ใช่ความสามารถของ Model เพียงอย่างเดียว แต่เป็นส่วนหนึ่งของ Harness ที่ทำงานร่วมกับมัน
.
จึงมีคำอธิบายหนึ่งว่า
> **Agent = Model + Harness**
พูดให้เห็นภาพก็คือ สมองบวกกับร่างกาย
Model เป็นส่วนที่คิด ส่วน Harness เป็นส่วนที่จัดการให้ความคิดนั้นกลายเป็นกระบวนการทำงาน
ทั้งสองส่วนมีหน้าที่ต่างกัน แต่ต้องทำงานร่วมกัน
.
ลองนึกถึง Model ตัวเดียวกัน แต่ถูกนำไปวางใน Harness คนละแบบ
ชุดหนึ่งอาจจัดการบริบทได้แบบหนึ่ง มีเครื่องมือให้ใช้แบบหนึ่ง และมีลำดับการทำงานอีกแบบหนึ่ง
อีกชุดอาจจัดการสิ่งเหล่านี้ต่างออกไป
แม้จะใช้สมองตัวเดียวกัน วิธีทำงานและผลลัพธ์ที่ได้ก็อาจไม่เหมือนกัน
เพราะสิ่งที่ลงมือทำงานจริงไม่ใช่ Model ที่แยกออกมาโดด ๆ แต่เป็น Model ที่ทำงานอยู่ภายใน Harness
.
นี่จึงเป็นเหตุผลว่าทำไมการพูดว่า Model ตัวไหนเก่งกว่า อาจยังไม่เพียงพอที่จะอธิบายว่า Agent ตัวไหนทำงานได้ดีกว่า
การเปรียบเทียบเฉพาะสมอง บอกเราได้เพียงส่วนหนึ่ง
แต่ยังไม่ได้บอกว่าร่างกายจัดการงานอย่างไร หรือทั้งสองส่วนทำงานร่วมกันได้ดีแค่ไหน
.
## #สรุปแบบวิศวกรเป็ด
Model กับ Harness ไม่ใช่สิ่งเดียวกัน
Model คือส่วนที่คิด ส่วน Harness คือระบบที่จัดการให้การคิดนั้นเชื่อมต่อกับข้อมูล เครื่องมือ และขั้นตอนการทำงาน
Agent ไม่ได้เกิดจากสมองที่เก่งอย่างเดียว แต่เกิดจากสมองและระบบที่ทำให้สมองนั้นลงไปทำงานร่วมกัน
.
