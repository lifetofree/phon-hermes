# Grok Bot กับ Rakazo — AI Teammates แนวคิดใกล้กัน แต่ถูกเลี้ยงคนละบ้าน

เทียบกัน 20 พ.ย. — ฝั่งหนึ่งใช้ AI Team ผ่าน Cloud ของผู้ให้บริการ เริ่มต้นที่แผน $30 ต่อเดือน อีกฝั่งติดตั้ง Rakazo แบบ Self-hosted บนเครื่องตัวเอง ใช้ซอฟต์แวร์ฟรี แต่ต้องดูแลระบบเอง
.
แนวคิดเดียวกัน แต่คนละสภาพแวดล้อม
บอตที่มีชื่อของตัวเอง มีคอมพิวเตอร์ให้ใช้ มีความจำ มีตารางงาน ทำงานขนานกันได้ และขออนุมัติก่อนแตะสิ่งสำคัญ
องค์ประกอบเหล่านี้เป็นแนวคิดของ AI Teammates ที่พบได้ทั้งใน Grok Bot และ Rakazo
Grok Bot 1.0 ตามประกาศของทีมผู้พัฒนา เพิ่มความสามารถสำคัญสามอย่าง
ส่วน Rakazo เป็น Open Source Alternative ที่ทีมผู้พัฒนาระบุไว้ใน README
ในรูปแบบ Self-hosted บอตแต่ละตัวทำงานอยู่บนสภาพแวดล้อมที่เราติดตั้งและดูแลเอง มีระบบแชตกลุ่มสำหรับแบ่งงาน มีตารางงาน และสามารถเลือกใช้โมเดลได้ตามระบบที่รองรับ
แนวคิดของทั้งสองระบบจึงใกล้กันในระดับ AI Team แต่ไม่ได้หมายความว่าความสามารถทุกด้านเท่ากัน
ความต่างสำคัญอยู่ที่ว่าใครเป็นคนดูแลสภาพแวดล้อมที่บอตทำงานอยู่ และใครเป็นคนรับผิดชอบทรัพยากรเหล่านั้น
.
เทียบกันหกแกน
การเปรียบเทียบนี้ใช้ Grok Bot ฝั่ง Cloud กับ Rakazo แบบ Self-hosted เท่านั้น
1. ที่อยู่ของบอต
Grok Bot — บอตทำงานบน Cloud Computer ในสภาพแวดล้อมของผู้ให้บริการ
Rakazo Self-hosted — บอตทำงานบนเครื่องหรือสภาพแวดล้อมที่เราติดตั้งและดูแลเอง
2. โมเดล
Grok Bot — ใช้โมเดล Grok ตามข้อจำกัดของบริการ ส่วนโมเดลอื่นไม่ได้อยู่ในตัวบอตโดยตรง
Rakazo Self-hosted — เลือกใช้โมเดลได้หลากหลาย ทั้งผ่าน API Key ของเราและโมเดลที่รันบนเครื่อง ตาม Provider และความสามารถที่ระบบรองรับ
3. ราคาเริ่มต้น
Grok Bot — บอตเริ่มใช้งานได้ตั้งแต่แผน $30 ต่อเดือนขึ้นไป ส่วนแผน $8 ไม่มีบอต
Rakazo Self-hosted — ตัวซอฟต์แวร์ฟรี ภายใต้ Apache-2.0 แต่ยังมีต้นทุนด้านเครื่อง ระบบ โมเดล และการดูแล
4. โควตา
Grok Bot — ใช้โควตาแบบ Pool รายสัปดาห์ร่วมกับแชต ภาพ เสียง และ Cursor
Rakazo Self-hosted — ข้อจำกัดขึ้นอยู่กับทรัพยากรเครื่อง โมเดล และ API ที่เลือกใช้ ไม่มีโควตากลางแบบเดียวกับบริการ Cloud ที่นำมาเปรียบเทียบ
5. ความจำของทีม
Grok Bot — ความจำของบอตและทีมอยู่ใน Cloud Computer ภายใต้บัญชีผู้ให้บริการ
Rakazo Self-hosted — จัดเก็บความจำในสภาพแวดล้อมที่เราดูแลเอง ทำให้เราควบคุมตำแหน่งจัดเก็บและการจัดการข้อมูลได้มากขึ้น
อย่างไรก็ตาม ถ้าเลือกใช้โมเดลผ่าน External API ข้อมูลที่ส่งไปประมวลผลก็อาจออกนอกเครื่องได้ การเก็บ Memory ในเครื่องตัวเองไม่ได้แปลว่าข้อมูลทุกอย่างจะอยู่ในเครื่องเสมอไป
6. การย้ายระบบ
จาก Grok Bot มายัง Rakazo Self-hosted สามารถย้ายข้อมูลบางส่วนได้
สิ่งที่ย้ายมาได้ตามข้อมูลที่ทีม Rakazo ระบุ ได้แก่
ส่วน Chat History ไฟล์บนเครื่อง และสถานะ Sign-in ยังค้างอยู่ในระบบเดิม
การย้าย AI Team จึงไม่ใช่แค่ย้ายตัวบอต แต่ต้องดูด้วยว่าองค์ประกอบใดของทีมที่ย้ายตามมาได้ และองค์ประกอบใดยังผูกอยู่กับแพลตฟอร์มเดิม
.

วันที่ 18 พ.ย. ทั้งสองฝั่งมีการออกเวอร์ชันใหม่ในคืนเดียวกัน
ฝั่ง Grok Bot — Changelog ระบุเวอร์ชันแอปล่าสุด v1.2.3 เพิ่มการกำหนดสิทธิ์เครื่องมือเป็นสี่ระดับ ตั้งแต่การอนุญาตอัตโนมัติไปจนถึงการบล็อก และเพิ่มระบบแจ้งเตือนให้ Reconnect เมื่อ Routine หมดสถานะ Sign-in
ฝั่ง Rakazo Self-hosted — ออก v0.13.0 ขยายกฎ Approval ให้ครอบคลุมทั้ง Routine และแชตที่เชื่อมต่อ
ส่วนโมเดล Grok 4.7 เปิดให้ใช้งานผ่าน API เมื่อวันที่ 13 พ.ย. ตาม Release Notes
จังหวะนี้ทำให้เห็นความต่างของวิธีดูแลระบบ
ฝั่ง Grok Bot มีการจัดการอัปเดตให้ผู้ใช้ แอปอัปเดตและรีสตาร์ทเองเมื่อพร้อม
ส่วน Rakazo Self-hosted ผู้ใช้ต้องเป็นคนดึงเวอร์ชันใหม่และจัดการอัปเดตด้วยตัวเอง
ทั้งสองฝั่งมีการพัฒนาต่อเนื่อง แต่ภาระในการนำเวอร์ชันใหม่มาใช้งานอยู่คนละฝั่ง
บ้านหนึ่งมีคนดูแลให้ อีกบ้านเราต้องดูแลเอง
.
ราคาของบ้านเช่า
ตามหน้าราคา Grok Bot ไม่ได้อยู่ในแผนถูกที่สุดที่มี
แผน $8 มีแชต เสียง และสร้างภาพ แต่ไม่มีบอต ต้องขยับไป $30 ขึ้นไปจึงจะใช้บอตได้
ถ้าต้องการให้บอตทั้งทีมใช้งานร่วมกัน ต้องขยับไปแผน Team ขึ้นไป ส่วนการให้บอตเข้าประชุมก็มีเงื่อนไขของแผนเพิ่มเติม
โควตาเป็น Pool รายสัปดาห์ที่ใช้ร่วมกันระหว่างแชต ภาพ เสียง บอต และ Cursor
หมายความว่างานบอตที่ใช้ทรัพยากรมากในวันเดียว อาจกินโควตาที่ต้องใช้ร่วมกันตลอดสัปดาห์ หากต้องการใช้งานต่อก็มีทางเลือก Top-up เพิ่ม
เรื่องโมเดลก็มีข้อจำกัดตามบริการ
ตัวบอตใช้โมเดล Grok ส่วนโมเดลอื่นไม่ได้อยู่ในบอตโดยตรง การใช้โมเดลอื่นมีเฉพาะใน Cursor ซึ่งเป็นส่วนเขียนโค้ด และคิดค่าบริการตามราคา API แยกต่างหาก
อีกเรื่องที่สำคัญคือความจำ
ความจำของบอตและทีมอยู่บน Cloud Computer ในบัญชีของผู้ให้บริการ ทีม Rakazo จึงเขียนวิธีย้ายบอตออกมาไว้ในระบบของตัวเอง
แต่สิ่งที่ย้ายได้ยังมีขอบเขต Chat History ไฟล์บนเครื่อง และสถานะ Sign-in ไม่ได้ย้ายตามมาทั้งหมด
ต้นทุนของบ้านเช่าจึงไม่ได้มีแค่ค่าสมาชิก แต่รวมถึงข้อจำกัดของโควตา โมเดล และข้อมูลที่ยังผูกอยู่กับแพลตฟอร์ม
.
ราคาของบ้านเรา
Rakazo Self-hosted เป็นซอฟต์แวร์ฟรีภายใต้ Apache-2.0
แต่คำว่าใช้ฟรีไม่ได้หมายความว่าไม่มีต้นทุน
ค่าใช้จ่ายอีกด้านคือการดูแลระบบด้วยตัวเอง
ทั้งหมดนี้เป็นความรับผิดชอบของเรา
บนเครื่องที่ใช้อยู่ก็ยังมีงานเก็บกวาดค้างอยู่หนึ่งรายการ
สิ่งที่แลกกลับมาคือความยืดหยุ่นในการเลือกโมเดล การจัดการสภาพแวดล้อม และการควบคุมตำแหน่งจัดเก็บข้อมูลได้มากขึ้น
แต่ต้องจำไว้ว่า Self-hosted ไม่ได้ทำให้ทุกอย่างปลอดภัยหรือเป็นส่วนตัวโดยอัตโนมัติ
ถ้าเลือกใช้ External API เราก็ยังต้องรับผิดชอบว่าอะไรถูกส่งออกไป และส่งไปให้ใคร
เราไม่ได้ซื้อความสะดวกจากผู้ให้บริการ แต่รับภาระดูแลระบบมาไว้กับตัวเอง
.
## #สรุปแบบวิศวกรเป็ด
Grok Bot กับ Rakazo มีแนวคิด AI Teammates ที่ใกล้กัน แต่รูปแบบการให้บริการและการรับผิดชอบระบบต่างกัน
Grok Bot ให้ความสะดวกผ่าน Cloud ผู้ให้บริการดูแลโครงสร้างพื้นฐานและการอัปเดตให้ แต่เราต้องยอมรับเงื่อนไขเรื่องราคา โควตา โมเดล และข้อมูลที่อยู่ในแพลตฟอร์ม
Rakazo Self-hosted ให้เราเลือกและจัดการสภาพแวดล้อมได้มากขึ้น แต่ต้องรับผิดชอบเรื่องเครื่อง โมเดล Credential ความปลอดภัย และการบำรุงรักษาเอง
คำถามจึงไม่ใช่ว่าฝั่งไหนเก่งกว่า
แต่คือเราอยากรับผิดชอบอะไร และอยากให้ใครเป็นคนถือกุญแจของระบบ AI Team
บ้านเช่าจ่ายเพื่อความสะดวก ส่วนบ้านเราจ่ายด้วยความรับผิดชอบ
ไม่มีแบบไหนดีกว่าสำหรับทุกคน มีแต่แบบที่เหมาะกับระดับการควบคุมและภาระดูแลที่เรายอมรับได้
.

.
