# AI-Token-Monitor

---

เรื่องมันเกิดจากตัวแอดเอง ใช้ AI หลายเจ้า(สายทดลอง) หลายๆ ท่านคงผ่านวิชา “บริหาร Token 101” กันมาแล้ว ส่วนตัวแอดเองเกิด pain point ว่า เราเป็น OPB ใช้งานคนเดียว จะคอยมาเช็คทีละเจ้ามันก็วุ่นวาย และบางทีใช้เพลินจนติด limit โดยที่ยังไม่ได้ Update file ที่แอดใช้ให้ AI Update งาน เพื่อให้ AI อีกตัวมารับงานต่อได้ T_T
.
version แรก แอดทำ python มาเขียน firebase ทุกๆ 30s และให้ Controller ที่ต่อ Wi-fi มาดึงไปแสดงผลที่จอขาว-ดำ ทีละแบรนด์ มี switch 1 ตัวใช้ Swap แต่ละแบรนด์หรือเปลี่ยน Mode เป็น Swap auto ทุกๆ 6s
.
version ต่อมา แอดปรับมาเป็นทำ Dashboard เพิ่ม เผื่ออยากเปิดดูบน Web (งานหาทำนั่นแหละ) และใช้ Process ในการแสดงผลบนหน้าจอเหมือนกับ version แรก
.
version ล่าสุด ก่อนจะมี version นี้ เหตุเเกิดจาก มันยังคันมืออยู่ เลยเปลี่ยนจอแสดงผลเป็นจอสีและเพิ่มขนาดอีกนิดชะเลย จะได้มีพี้นที่แสดงผลได้เพิ่ม ^_^
