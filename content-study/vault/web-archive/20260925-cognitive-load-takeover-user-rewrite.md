# คู่มือที่เราใช้

— **Layer 2 — สมองส่วนแจ้งเตือน:** ตอบสนองต่อสิ่งเร้า ดราม่า ของใหม่ เร็ว และไม่มีการวางแผน

— **Layer 1 — ร่างกาย:** หายใจ ใจเต้น ความรู้สึกเหนื่อย

ความจริงที่สำคัญไม่ใช่แค่ Layer 2 ที่รวดเร็ว

ตอน Load ปกติ
