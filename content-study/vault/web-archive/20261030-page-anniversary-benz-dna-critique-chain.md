- KEEP: "คำตอบคือระบบ วิธีคิด และวิธีแก้ปัญหาที่ลองผิดลองถูกมาเอง" + เพิ่มน้ำหนัก "ตกผลึกจนอยากอธิบายให้คนอื่นเข้าใจ" + "นั่นคือข้อมูลที่ทำให้เนื้อหาถัดไปดีขึ้น"
- DEAD checks: "เขียนทุกวัน" = 0 (≠360, r1 จุด 1) | "ขาลงจริง ๆ" เดาะ ๆ ไม่มีตัววัด = 0 → เขียนเป็นประสบการณ์ | "ไม่ใช่แรงบันดาลใจ" แบบฟันธงในหัวเรื่อง/บทสรุป = 0 (ไม่พิสูจน์สิ่งเดียวกัน) | "สาระดี ๆ ยิ่งขึ้นไป" กว้างเปล่า = 0 | ห้ามเติม AI/automation/เครื่องมือปัจจุบัน (r2 §3)
