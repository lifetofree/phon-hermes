# เลือก AI harness ด้วย model เดิม — แต่ลืมว่าเราเปลี่ยนทั้งคู่

## ร่างทั้ง 6 LEVEL (ทดลอง — หัวเรื่อง/แกนเดียวกัน, ความลึก insight ต่างกันตาม ladder ของบ้าน: L1 วิธี / L2 ทำผิดไม่รู้ตัว / L3 เชื่อผิดไม่รู้ตัว / L4 วินิจฉัยผิด / L5 ทำนายก่อน / L6 opportunity-shift)

---

### L1 — how-to-fix (วิธีใช้: เลือกให้เป็น งานละครั้ง)

มีคนถามว่า AI harness ตัวไหนดีที่สุด

คำตอบที่ใช้ได้คือ ไม่ตอบด้วยชื่อ แต่ตอบด้วยงาน

วิธีคือ จับทีละงาน ให้คะแนนตัวเลือก 1 ถึง 5 ใน 6 ช่อง

งานพอดีไหม ติด model ใครไว้ รันเองได้ไหม ปลอดภัยตั้งต้นแค่ไหน เห็นค่าใช้จ่ายต่อรอบไหม ทีมคุ้นไหม

ช่องไหนงานนี้พึ่งจริง ให้น้ำหนักมันมาก

แล้วเลือกทีละงาน ไม่เลือกให้ทั้งทีมงานครั้งเดียว

ครั้งหน้าเจองานใหม่ ทำซ้ำชุดเดิม หกช่อง สองนาที

.

### L2 — doing-wrong-unnoticed (ทำอยู่โดยไม่รู้ตัว: เทียบชื่อแทนที่จะเทียบคู่) ← แนะนำ

ทุกครั้งที่จะเลือก AI harness เรามักเปิดลิสต์ แล้วเทียบกันทีละชื่อ

ฟีเจอร์เยอะกว่า เปิดให้ครบกว่า คนพูดถึงเยอะกว่า

แต่มีประโยคหนึ่งว่ากันว่า Agent คือ model บวก harness

แปลว่าสิ่งที่ลงงานจริง ไม่ใช่ harness ชิ้นเดียว แต่เป็นคู่ของมันกับ model

ลิสต์ที่เทียบชื่อ เทียบแต่ครึ่งเดียวของสิ่งที่จะลงไปทำงาน

จบแล้วแปลกใจว่าทำไมของที่รีวิวดีมาก มาอยู่กับงานเราแล้วไม่เหมือนรีวิว

> **เราไม่ได้เลือก harness เราเลือกทั้งคู่โดยดูฝั่งเดียว**

model เดิม สลับ harness แล้วผลงานเปลี่ยน กลับกันก็เปลี่ยน

คู่ที่ดีในงานนี้ ไม่ได้ดีเพราะตัวไหนเก่ง แต่เพราะเข้ากันแล้วเข้ากับงาน

ครั้งหน้าเจอลิสต์เทียบชื่อ ให้ถามกลับว่า model ฝั่งไหน เพราะเรากำลังเลือกคู่ ไม่ได้เลือกของชิ้นเดียว

.

**สิ่งที่ลงงานคือคู่ การเทียบชื่อจึงเห็นครึ่งเดียวตั้งแต่ยังไม่เริ่ม**

### L3 — believing-wrong-unnoticed (เชื่ออะไรผิดอยู่: เชื่อว่ามีตัวเลือกที่ดีที่สุดรออยู่)

มีความเชื่อหนึ่งว่า ถ้าค้นพอมาก เราจะเจอ AI harness ที่ดีที่สุด แล้วปิดเคส

ประโยคว่า Agent คือ model บวก harness บอกตรงกันข้าม

สิ่งที่ลงงานเป็นคู่ การเพิ่มตัวเลือกเข้าลิสต์ ยิ่งเพิ่มจำนวนคู่ ไม่ใช่ยิ่งใกล้คำตอบ

ลองดูตัวเองย้อนหลัง ถ้าเคยเปลี่ยน harness แล้วงานเปลี่ยน ตัวที่เปลี่ยนอาจไม่ใช่ฝั่ง harness

แต่เป็นคู่ที่จัดวางใหม่ทั้งคู่ คำตอบเก่าจึงหมดสิทธิ์ตั้งแต่ตอนนั้น

ความเชื่อว่ามีตัวที่ดีที่สุด ทำให้เราถามคำถามที่ไม่มีคำตอบ แล้วผิดใจกับทุกคำตอบที่ได้

> **คำถามไม่ผิดเพราะยาก มันผิดเพราะดีที่สุดไม่ใช่สมบัติของชิ้นเดียว มันเป็นของคู่**

ถ้าไม่มีชิ้นที่ดีที่สุด งานที่ต้องทำคือเลือกคู่ให้เข้างาน งานละงาน

คำถามที่เหลือจึงไม่ใช่ ตัวไหนดีที่สุด แต่คือ คู่นี้เข้ากับงานนี้ไหม

.

**ดีที่สุดไม่ได้อยู่บนชิ้นใดชิ้นหนึ่ง มันอยู่บนคู่ที่จับกับงานได้พอดี**

### L4 — wrong-diagnosis (วินิจฉัยผิด: งานช้า/งานพัง เพราะ harness เลือกผิด ทั้งที่ปัญหาคือไม่ได้มองว่าเป็นคู่)

งาน AI agent เริ่มออกแบบ เริ่มช้า เริมสะดุด การวินิจฉัยแรกของเรามักเป็นฝั่งเดียว

สลับตัว อัปเวอร์ชัน หาตัวใหม่ แล้วงานก็ยังเดิม

เพราะสิ่งที่ลง field คือคู่ การวินิจฉัยฝั่งเดียวจึงแก้ไม่เข้า อาการเดิมมาจากการจับคู่ที่ขยับ

มีประโยคว่ากันว่า performance เป็นฟังก์ชันของ harness กับ model ร่วมกัน

เวลาอาการขึ้น แปลว่าอย่างน้อยหนึ่งฝั่งในคู่ขยับไปแล้ว มองเฉพาะฝั่งเดียวจึงเจอแต่เงา

> **อาการไม่ได้อยู่ที่ชิ้นส่วน มันอยู่ที่การจับคู่ วินิจฉัยฝั่งเดียวจึงเจอแต่เงาของมัน**

การวินิจฉัยใหม่จึงเริ่มที่คู่ ฝั่งนี้เพิ่งเปลี่ยนไหม อีกฝั่งเพิ่งเปลี่ยนไหม งานที่ทำเพิ่งเปลี่ยนไหม

สามคำถามนี้จับคู่ที่ขยับ ก่อนจะเทียบชื่อใหม่ทั้งลิสต์

.

**อาการอยู่ที่คู่ ไม่ใช่ชิ้นส่วน เลิกมองฝั่งเดียวจึงหยุดวินิจฉัยผิด**

### L5 — predict-before-others (ไม่ default — ต้องมีกลไกที่สังเกตจากเคสจริง + hedge ตาม owner rule item 319)

มีกลไกหนึ่งกำลังขยับอยู่ ว่ากันว่า Agent คือ model บวก harness

ทุกครั้งที่ model เก่งขึ้น ส่วนที่ harness ต้องทำแทนจะเหลือน้อยลง ส่วนที่เหลือคือชิ้นที่ยังแข็งพอ

ถ้าเป็นเช่นนั้น คุณค่าของ harness จะย้ายจากความหนา ไปอยู่ที่จุดที่ model ยังทำแทนไม่ได้

ของที่ยังอยู่คือ กติกา การจำกัดขอบเขต และการตรวจงาน

สิ่งที่เรายังพูดไม่ได้คือจังหวะ รู้แค่ว่ากลไกนี้กำลังเดิน ไม่รู้ว่าอีกกี่ไตรมาส

> **ยิ่ง model เก่ง มูลค่าของ harness ยิ่งย้ายไปที่กติกา ไม่ใช่ความหนา**

อ่านข่าวใหม่ในงานนี้ด้วยสายตาเดียว อย่าถามว่าใครแพงกว่า ให้ถามว่ากติกาฝั่งไหนยืนได้นานกว่า

เราไม่ทำนายผู้ชนะ เราอ่านทิศทางที่มูลค่ากำลังย้าย

.

**ของที่เหลืออยู่คือกติกา สายตาที่อ่านข่าวตรงนั้นก่อน คือตัวเงียบที่ได้เปรียบ**

### L6 — opportunity-shift (จังหวะตลาดเปลี่ยน: มาตรฐานทั้งองค์กรเริ่มกลายเป็นของล้าหลัง)

มีประโยคหนึ่งว่ากันว่า การตั้งมาตรฐาน harness เดียวทั้งองค์กร คือการเดิมพันว่าคู่นี้จะไม่เก่าในไตรมาสเดียว

แต่สิ่งที่ลงงานคือคู่ คู่มีอิสระจะเก่า ไม่มีใครห้าม

เมื่อมาตรฐานเดิมเก่า องค์กรที่ล็อกตัวเองไว้กับคู่เดียว จะเจอต้นทุนสองชั้น ต้นทุนเปลี่ยน และต้นทุนที่ทั้งระบบผูกกับมาตรฐานเดิมมาสูงเกินจะคลาย

ขณะเดียวกัน ผู้ที่เคยชินกับการเลือกทีละงาน จะย้ายคู่ได้โดยไม่ต้องรื้ออะไร

ระหว่างสองแบบนี้ ไม่ใช่เรื่องความเก่ง แต่เป็นเรื่องโครงสร้างที่ตั้งไว้ก่อนแล้ว

> **ตลาดไม่ได้เปลี่ยนเพื่อลงโทษใคร มันเปลี่ยนแล้วดันมาตรฐานเก่าให้กลายเป็นต้นทุน**

จังหวะไม่ได้อยู่ที่ว่าเมื่อไรจะเกิด อยู่ที่ว่าโครงสร้างไหนรออยู่ในตำแหน่งที่โดนก่อน

องค์กรที่เลือกคู่ได้ทีละงาน ยืนอยู่ตรงที่โอกาสมาถึง ไม่ใช่ตรงที่ต้นทุนมาถึง

.
